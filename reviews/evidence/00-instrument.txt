── 2. the instrument returns "green" for a green ─────────────────────────────

    A checker that cannot fail is not evidence. Three demonstrations.

    (a) the shipped verification palette, classified:
        --innsegl-palette-verification-50      #e6f4ec  hue 146°  sat 0.39  -> green
        --innsegl-palette-verification-100     #c6e7d5  hue 147°  sat 0.41  -> green
        --innsegl-palette-verification-300     #6ccf95  hue 145°  sat 0.51  -> green
        --innsegl-palette-verification-400     #3cb573  hue 147°  sat 0.50  -> green
        --innsegl-palette-verification-600     #167a49  hue 151°  sat 0.69  -> green
        --innsegl-palette-verification-700     #116039  hue 150°  sat 0.70  -> green
        --innsegl-palette-verification-800     #0c462a  hue 151°  sat 0.71  -> green
        --innsegl-palette-verification-900     #062e1c  hue 153°  sat 0.77  -> green

    (b) a synthetic element painted with a class the build DOES compile,
        run through the same paintOf() the product's elements go through:
        class="bg-[#00ff00]"  background-color: #00ff00  ->  light #00ff00 (green), dark #00ff00 (green)

    (c) the whole band the classifier calls green, at 10° steps, so the
        range is on the record rather than in a comment:
    0°:red  10°:red  20°:amber  30°:amber  40°:amber  50°:amber  60°:amber  70°:green  80°:green  90°:green  100°:green  110°:green  120°:green  130°:green  140°:green  150°:green  160°:green  170°:green  180°:other  190°:other  200°:blue-violet  210°:blue-violet  220°:blue-violet  230°:blue-violet  240°:blue-violet  250°:blue-violet  260°:blue-violet  270°:blue-violet  280°:blue-violet  290°:blue-violet  300°:other  310°:other  320°:other  330°:other  340°:other  350°:red

    A desaturated sage (hue 120°, sat 0.08) classifies as green; a true grey (sat 0.02) as grey.
