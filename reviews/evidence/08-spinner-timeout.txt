── nothing spins — the other half of the anti-pattern's name ─────────────────

    doc 06 §5.5 permits motion for "state transitions and focus movement
    only", and ADR-0038 decision 4 says the theme ships no keyframe
    animation. Measured against the BUILT stylesheet:

    @keyframes blocks in the built stylesheet:      0
    animation / animation-* declarations:          0

    So the loading indicator cannot be a spinner: there is nothing in the
    build for it to spin with. What it draws instead, from the DOM:
    <circle cx="3.5" cy="8" r="1.25" fill="currentColor" stroke="none"></circle>
    <circle cx="8" cy="8" r="1.25" fill="currentColor" stroke="none"></circle>
    <circle cx="12.5" cy="8" r="1.25" fill="currentColor" stroke="none"></circle>

── prefers-reduced-motion, which is the transition's own bound ───────────────

    doc 06 §5.5: "Respect prefers-reduced-motion." The token sheet
    collapses both durations under the query rather than leaving it to
    each component. From the built stylesheet:

        @media(prefers-reduced-motion:reduce) :root { --innsegl-motion-duration-fast: 1ms }
        @media(prefers-reduced-motion:reduce) :root { --innsegl-motion-duration-default: 1ms }
        @media(prefers-reduced-motion:reduce) * { scroll-behavior: auto!important }
        @media(prefers-reduced-motion:reduce) * { transition-duration: 1ms!important }
        @media(prefers-reduced-motion:reduce) :before { scroll-behavior: auto!important }
        @media(prefers-reduced-motion:reduce) :before { transition-duration: 1ms!important }
        @media(prefers-reduced-motion:reduce) :after { scroll-behavior: auto!important }
        @media(prefers-reduced-motion:reduce) :after { transition-duration: 1ms!important }

── what this probe cannot determine ──────────────────────────────────────────

    Whether the timed-out state is VISIBLE — painted, on screen, not
    covered — is a rendering question jsdom cannot answer. This probe
    measures that the DOM changes to an explicit error at the bound, and
    that the words are there to be read. A browser is needed to confirm
    that a reader sees them, and that is #57's harness.
