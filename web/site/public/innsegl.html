Go module

innsegl.dev/innsegl

The name Innsegl is imported and installed by. The code is at github.com/Raymalian/innsegl; this domain serves the name, so it stays the project's own.

Get started Source on GitHub

Install

go install innsegl.dev/innsegl/cmd/innsegl@latest

No tagged release yet, so @latest builds the default branch. The module is a program, not a library.

How the name resolves

go asks https://innsegl.dev/innsegl?go-get=1 and reads one tag from this page: 

<meta name="go-import"
      content="innsegl.dev/innsegl git https://github.com/Raymalian/innsegl">

Every path under the module, such as innsegl.dev/innsegl/cmd/innsegl, gets this same page.
